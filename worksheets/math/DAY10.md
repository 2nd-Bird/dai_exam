## DAY10A — = は「同じ」、不等号は「境界」

### 0 EXACT / LIMIT

1本150円の飲み物を x 本と、500円のお菓子を買う。

- 合計が **800円ちょうど**  
  `150x + 500 = 800`
- 合計が **800円以下**  
  `150x + 500 ≤ 800`

`=` は左右が同じ。  
不等号は「どちらまでOKか」を表す。

### 1 SYMBOL CODE

- より大きい → `>`
- より小さい → `<`
- 以上 → `≥`
- 以下 → `≤`
- ちょうど / 等しい → `=`

(1) 800円以上 → `____ 800`

(2) 800円未満 → `____ 800`

(3) 800円以下 → `____ 800`

(4) 800円より高い → `____ 800`

### 2 SITUATION → FORMULA

(1) 1冊60円のノートを x 冊買い、300円のペンケースも買った。合計は900円。

途中:
- ノート代 = `60x`
- 全部 = `60x + 300`

式: `________________ = 900`

(2) 1個120円のパンを x 個買う。代金は600円以下。

式: `________________ ≤ 600`

(3) a人いた。7人帰ったら5人残った。

式: `________________ = 5`

(4) a円からb円を引いた差は900円以上。

式: `________________ ≥ 900`

### 3 CHECK — 数を入れて左右を見る

`3x+2 = 14`

(1) x=4 を入れる。

左: `3×4+2 = ____`  
右: `14`

左右は  同じ / 違う

(2) `2x+5 > 10` に x=4 を入れる。

左: `2×4+5 = ____`  
右: `10`

`____ > 10` は  成り立つ / 成り立たない

### 2 STONE SQUARE — 四角形の外周

1辺に n 個ずつ石を並べて、正方形の外周を作る。

まず4辺を別々に数えると `4n` 個。

でも4つの角は2回ずつ数えている。  
だから4個引く。

`石の数 = 4n - 4`

(1) 1辺5個 → `4×5-4 = ____` 個

(2) 1辺10個 → `4×10-4 = ____` 個

(3) 1辺n個 → `________________` 個

### 3 ANOTHER SHAPE — 正五角形なら？

1辺に n 個ずつ石を並べて、正五角形の外周を作る。

5辺で `5n`。  
5つの角を2回ずつ数えているので5個引く。

(1) 石の数 = `________________`

(2) n=4 → `________________ = ____` 個

### 4 FINAL CONNECT

正方形の石の数 `4n-4` が **36個以下**。

「解く」のではなく、関係を式にする。

`________________ ≤ 36`
