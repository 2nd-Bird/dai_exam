# 数学 DAY7 — xで長い式を圧縮する

- 対応INDEX: `M02-01〜04`
- REUSE: `M01-12`（累乗）
- 構成: A/B 2セッション
- 設計: DAY6では共同なら理解できた一方、独力では設問・注意書きを十分に読まず暗算へ飛びやすかった。DAY7は説明文を増やさず、完成例と式そのものを視界の中心に置く。今回は計算より「長い表し方を短く圧縮する」ことを主題にする。

## DAY7A — xで「全部の場合」を1本にする

### 0 PATTERN — 1個ずつ数えない

正方形を横につなぐ。

- 1個 → 棒 4本
- 2個 → 棒 7本
- 3個 → 棒 10本
- …
- x個 → 棒 `1 + 3x` 本

(1) 4個なら、`1 + 3×4 = ____` 本

(2) 10個なら、`1 + 3×10 = ____` 本

(3) 「正方形が何個でも使える式」はどちら？

`1 + 3×10` / `1 + 3x`

### 1 COMPRESS — ×を消して短くする

完成例:

- `3×x = 3x`
- `x×3 = 3x`
- `a×b = ab`
- `1×x = x`
- `(-1)×x = -x`

(1) `4×x = ____`

(2) `y×5 = ____`

(3) `2×a×b = ____`

(4) `(-1)×m = ____`

### 2 POWER — 同じ文字の積は累乗

完成例:

- `x×x = x²`
- `x×x×x = x³`
- `3×x×x = 3x²`

(1) `a×a = ____`

(2) `b×b×b = ____`

(3) `5×x×x = ____`

### 3 COEFFICIENT — 文字の前の数

`7x` の係数は `7`。

(1) `4a` の係数 = ____

(2) `-3x` の係数 = ____

(3) `-y` の係数 = ____

### LAST

`3x` はどちら？

`3+x` / `3×x`

## DAY7B — ÷と数量も文字式へ

### 0 DIVIDE — ÷を分数に圧縮

完成例:

- `a÷5 = a/5`
- `(x+3)÷2 = (x+3)/2`
- `3x÷4 = 3x/4`

(1) `x÷7 = ____`

(2) `5a÷2 = ____`

(3) `(a+b)÷6 = ____`

(4) `x÷(-3) = ____`

### 1 PRICE / LENGTH — 数量をそのまま式にする

(1) 1本120円のペンを x 本買う。

代金 = ____ 円

(2) 80cmのテープから x cm切る。

残り = ____ cm

(3) 1個 a g の品物3個と、1個 b g の品物2個。

重さの合計 = ____ g

### 2 RATE / SPEED — 割合・速さ

完成例:

`x kg の70% = 0.7x kg = 7x/10 kg`

(1) x円の10% = ____ 円

(2) a kmの道のりを2時間で進む。

速さ = ____ km/h

### 3 PI — πも文字と同じように使う

半径 r cm の円。

- 円周 = `2πr` cm
- 面積 = `πr²` cm²

(1) 半径 x cm の円の円周 = ____ cm

(2) 半径 a cm の円の面積 = ____ cm²

### ONE CHALLENGE

1冊90円のノートを x 冊買い、1000円払った。

おつり = ____ 円

## 解答

### DAY7A
- 0: (1) `13` (2) `31` (3) `1+3x`
- 1: (1) `4x` (2) `5y` (3) `2ab` (4) `-m`

- 3: (1) `4` (2) `-3` (3) `-1`

### DAY7B
- 0: (1) `x/7` (2) `5a/2` (3) `(a+b)/6` (4) `-x/3`
