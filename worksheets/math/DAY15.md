# 数学 DAY15 — 文字式 CORE + 方程式 MAINTENANCE

- 日付: 2026-09-04
- 主軸: `M02-02〜09`
- 方程式維持: `M03-03〜04`
- それとなく再利用: `M01-14`（÷分数 → ×逆数）
- 形式: A4 2枚、各ページ左右2列×6問、計24問。
- 紙面: 頭内処理で飛ばさないよう、各問に途中式の余白を確保。方程式は `=` の縦位置を固定して書く。

## 設計意図

DAY14は全体として概ね進んだが、`○○÷分数 = ○○×その分数の逆数` がすぐには出ず、理解に時間を要した。

DAY15では分数だけを独立した復習テーマにせず、文字式の `÷数` と方程式の係数処理の中へ自然に再登場させる。

優先して確認するもの:

1. `3x`, `2x²` のような係数・累乗の結合
2. 抽象数量を文字式へする
3. 負数を含む代入
4. x項と定数項を別種類としてまとめる
5. `-( )` の全項反転
6. 分配法則
7. 一次式の除法
8. ÷分数 → ×逆数
9. 方程式の `x=` を作る感覚を切らさない

## 見方

- 1〜6で崩れる: 文字式の読み方・代入を先にPATCH。
- 7〜11で崩れる: `x項と数字は別チーム`、`-( )は中の全部へ` をPATCH。
- 12〜18で崩れる: 分配・除法・分数をPATCH。
- 19〜24でだけ崩れる: 文字式より方程式の操作接続をPATCH。
- 15,16,22だけ崩れる: 分数全般ではなく、まず `÷分数→×逆数` の呼び出し不足を疑う。
