# 数学 DAY13 — EQUATION REPEAT + ONE LAYER

- 目的: DAY12 PAGE1で共同獲得した方程式の骨格を、**別数値・別形で自力再使用**する。
- 形式: A4 2枚、各12問。
- PAGE1（1〜12）: DAY12 1〜12の完全な別問題。図書館での独力復習向け。
- PAGE2（13〜24）: 方程式の骨格は同じまま、既習の累乗・分数・負のかっこ・両辺xを**1個ずつ**重ねる。
- 全問、解は整数。
- 各問は `=` の位置を固定し、縦4行の計算余白を置く。

## PAGE1 — DAY12 1〜12の別バージョン

1. `x+4=9` → 加法の移項
2. `x-6=2` → 減法の移項
3. `4x=20` → 係数で割る
4. `5x=-15` → 係数で割る + 負の解
5. `3x-4=11` → 2段階
6. `2x+7=17` → 2段階
7. `6x+1=4x+9` → 両辺x + 整数
8. `7x-5=3x+11` → 両辺x + 整数
9. `-3x+4=13` → 負係数
10. `5-2x=15` → x項が後ろ
11. `3(x+1)=18` → かっこ全体に3
12. `2(x-4)+3=9` → 分配 + 2段階

## PAGE2 — 方程式の骨格に、既習技能を1個だけ足す

13. `x+(-3)²=14`
   - cue: `(-3)²=9`
14. `2x=(-2)³+18`
   - cue: `(-2)³=-8`
15. `x/4+1=3`
   - cue: `x/4 = x÷4`
16. `(x+2)/3=4`
   - cue: `(x+2)` 全体を3で割る
17. `3x+1/2=19/2`
   - cue: 分数も左右へ同じ操作
18. `(2/3)x+1=5`
   - cue: `(2/3)x = (2/3)×x`
19. `-2(x-3)=8`
   - cue: `-2` はかっこ全体へ
20. `-3(x+2)+6=-9`
   - cue: まず分配
21. `4x+5=6x-3`
   - cue: x項を片側、整数を反対側
22. `-x+8=2x-1`
   - cue: `-x=(-1)x`
23. `2(x+2)+1=x+8`
   - cue: 分配 → x項をまとめる
24. `3(x-1)+(-2)²=x+9`
   - cue: 累乗 → 分配 → 移項
