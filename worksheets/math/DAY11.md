## DAY11A — 左右が同じになるxを探す

### 0 PACKET — xには相棒がいる

`3x+5` は

- xの項: `3x = 3×x`
- 数だけの項: `5`

`3x` と `5` は別の種類。

### 1 EQUATION — 未知の数をxにする

3個入りの箱が x 箱と、ばらで5個ある。全部で14個。

`3x + 5 = 14`

このように、xを含む等式を **方程式** という。

(1) 1袋4個のお菓子が x 袋と、ばらで2個。全部18個。

`________________ = 18`

(2) 1本120円のペンを x 本買った。代金は600円ちょうど。

`________________ = 600`

### 2 SOLUTION — 左右が同じなら「解」

方程式 `2x+1=7`

x=2:
- 左 `2×2+1 = ____`
- 右 `7`
- 同じ / 違う

x=3:
- 左 `2×3+1 = ____`
- 右 `7`
- 同じ / 違う

左右が同じになる x の値を **解** という。

### 3 CHECK — 答えは代入して1行確認

`3x+5=14` の解を x=3 と考えた。

`3×3+5 = ____`

右辺14と  同じ / 違う

### 4 LEFT / RIGHT

`4x-3 = 17`

- 左辺: `________________`
- 右辺: `________________`

`x=5` を入れる。

左: `4×5-3 = ____`

右: `17`

x=5 は 解 / 解ではない

## DAY11B — 天びんを崩さずxだけにする

### 0 BALANCE

`x+7 = 12`

左右から同じ7を引く。

`x+7-7 = 12-7`

`x = 5`

**左右に同じ操作をすれば、= は保たれる。**

### 1 ONE MOVE

(1) `x+6=10`

両辺に `-6`:

`x+6-6 = 10-6`

`x = ____`

(2) `x-4=-1`

両辺に `+4`:

`x-4+4 = -1+4`

`x = ____`

(3) `3x=-12`

両辺を `÷3`:

`3x÷3 = -12÷3`

`x = ____`

(4) `x/4=3`

両辺を `×4`:

`x/4×4 = 3×4`

`x = ____`

### 2 TWO MOVES — 1行ずつ

`2x+3=11`

まず両辺に `-3`:

`2x+3-3 = 11-3`

`2x = ____`

次に両辺を `÷2`:

`x = ____`

CHECK:

`2×____+3 = 11`

### 3 SHORTCUT — 移項は同じ操作の省略

`x+7=12`

両辺から7を引く処理を短く書くと

`x = 12-7`

右へ移った `+7` が `-7` に見えるのは、**両辺から7を引いた結果**。

(1) `3x-5=10`

`3x = 10 ____ 5`

`3x = ____`

`x = ____`

### 4 ONE CHALLENGE — xの項はxの項どうし

`5x = 6+3x`

両辺から `3x` を引く。

`5x-3x = 6+3x-3x`

`____x = 6`

`x = ____`

## 解答

### DAY11A
- 1: (1) `4x+2=18` (2) `120x=600`
- 2: x=2 → 5, 違う / x=3 → 7, 同じ。解は3
- 3: `14`, 同じ
- 4: 左辺 `4x-3`, 右辺 `17`; x=5 → 左17、解

### DAY11B
- 1: (1) 4 (2) 3 (3) -4 (4) 12
- 2: `2x=8` → `x=4`; CHECK `2×4+3=11`
- 3: `10+5` → `15` → `5`
- 4: `2x=6` → `x=3`; CHECK 左15、右15、同じ
