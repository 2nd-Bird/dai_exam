- 対応INDEX: `M03-02〜04`

## DAY12A — = の左右を同時に動かす

### 0 CHECK — xを数字へ置き換える

`2x+1=7` に `x=3`。

`2×3+1 = 7`

`7 = 7`

左右が同じ → `x=3` は解。

(1) `3x+2=14`, `x=4`

左: `3×4+2 = ____`

右: `14`

同じ / 違う

### 1 VERTICAL = — 両側から同じ数を引く

例:

```
x + 4 = 9
x + 4 - 4 = 9 - 4
x     = 5
```

`=` の位置はずっと同じ。

(1)

```
x + 6 = 10
x + 6 - 6 = 10 - 6
x     = ____
```

(2)

```
x - 3 = 5
x - 3 + 3 = 5 + 3
x     = ____
```

### 2 SAME THING — 移項は省略形

上の操作

```
x + 4 = 9
x + 4 - 4 = 9 - 4
x     = 5
```

を短く書くと

```
x + 4 = 9
x     = 9 - 4
x     = 5
```

**右へ行った `+4` が `-4` になったように見えるが、実体は両辺から4を引いた。**

(1)

```
x + 7 = 12
x     = 12 ____ 7
x     = ____
```

(2)

```
x - 5 = 2
x     = 2 ____ 5
x     = ____
```

## 解答

### DAY12A
- 0: 14, 同じ
- 1: (1) 4 (2) 8
- 2: (1) `-`, 5 (2) `+`, 7

### DAY12B
- 1: (1) 12 → 4 (2) 16 → 4
- 2: (1) 8 → 4 (2) 15 → 5
- 3: 5
- 4: 4, 13, 同じ
