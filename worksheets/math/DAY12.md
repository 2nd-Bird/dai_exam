# 数学 DAY12 — EQUATION DIAGNOSTIC 24

- 目的: 方程式を軸に、ここまで使った `係数 / 負数 / 累乗 / 分数 / かっこ / 分配 / 同類項 / 移項` を総動員し、**どこで詰まるかを問題番号から特定する**。
- 対応INDEX: `M01-10〜15, M02-05〜09, M03-02〜04`
- 形式: A4 2枚。各ページ2列×6問=12問、合計24問。
- 各問:
  - 初期式の `=` の真下に、計算用の `=` を4行固定。
  - 左右の余白を広く取り、途中式を頭内処理せず外に出す。
  - 解はすべて整数になる。
- DAY11で `=` の縦位置を固定すると等式変形が入ったため、その成功形を全問へ適用する。

## PAGE 1 — 方程式の骨格 + 符号 + かっこ

1. `x+2=3` → 両辺の同じ加減
2. `x-5=4` → 両辺の同じ加減
3. `3x=12` → 係数で両辺を割る
4. `-4x=20` → 負の係数 / 符号
5. `2x-3=7` → 2段階（定数→係数）
6. `3x+5=20` → 2段階（定数→係数）
7. `5x+2=3x+10` → 両辺のx項 / 移項
8. `6x-7=2x+9` → 両辺のx項 + 整数の加減
9. `-2x+5=11` → 負の係数 + 2段階
10. `4-3x=19` → x項が後ろ / 負の係数
11. `2(x+3)=14` → かっこ / 分配または両辺÷2
12. `3(x-2)+1=10` → 分配 + 2段階

## PAGE 2 — 累乗 + 分数 + 作用域 + 統合

13. `x+(-2)^2=7` → 負数の累乗（偶数乗）
14. `3x=(-2)^3+20` → 負数の累乗（奇数乗）+ 係数
15. `x/3+2=5` → 除法 / 分数表現
16. `(x-1)/2=3` → かたまり全体を割る
17. `2x+1/2=9/2` → 分数の加減 + 係数
18. `(3/2)x-1=5` → 分数係数 / 逆数
19. `-3(x-2)=12` → 負数×かっこ / 分配の作用域
20. `-2(x+4)+6=-10` → 負数×かっこ + 符号
21. `3x+4=5x-8` → 両辺x + 移項
22. `-2x+7=x-2` → 負のx項を含む移項
23. `2(x+1)+9=4x+3` → 分配 + 両辺x
24. `3(x-2)+(-2)^2=x+10` → 分配 + 累乗 + 両辺x の統合
