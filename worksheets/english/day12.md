## MODULE BOARD
- 近い → `this` / 遠い → `that`
- 正体を聞く → `What is this?` / 予想して聞く → `Is it ...?`
- 人を聞く → `Who is he/she?`
- 主役 → `he / she` / like の後ろ → `him / her`
- 疑問スイッチ → `Are / Do / Can`
- 知りたいもの → `what / who / when / where / how many`
- 日付 → `August 15` のように 月 + 日
