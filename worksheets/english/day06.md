# 英語 DAY6 — OBJECT / PERSON + QUESTION CONTROL PANEL

INDEX: E11 + E12 + E13  
設計: 状況 → まず口で言う → 1語/短い穴埋め → 声で反復 → 最後だけ短い全文

## A — OBJECT / PERSON MODULE

### MODULE
- 物の正体を知りたい → `What is this?`
- 「〜ですか？」と予想して聞く → `Is it ...?`
- 人の正体を知りたい → `Who is he? / Who is she?`
- 男性を文の主役にする → `he` / 女性 → `she`
- `like` の後ろで男性 → `him` / 女性 → `her`
- 教科書語彙: gift / character / nickname / sitar / aunt

### 1. 謎の楽器
**状況:** 海外VCで相手が見たことのない楽器を持っている。ギターっぽいが、違う気がする。まず正体を聞く。

`What is ______ ?`

相手: `It's a sitar.`

### 2. 予想して聞く
**状況:** まだギターに見える。念のため「ギターなの？」と聞く。

`______ it a guitar?`

相手: `No, it isn't.`

### 3. どこから来た？
**状況:** その楽器は買った物ではなく、おばさんからのプレゼントだった。

`It's a ______ from my aunt.`

### 4. 正体不明のキャラクター
**状況:** 相手が漫画の画面を見せてきた。女性キャラがいる。「誰、この人？」

`Who is ______ ?`

相手: `She is Maruko.`

### 5. 男性キャラを推す
**状況:** 今度はHarryの話。「彼、頭いいよ。かなり好き。」

`______ is smart.`  
`I like ______ very much.`

### 6. 女性キャラを推す
**状況:** Marukoの話に戻る。「彼女、おもしろい。私は彼女が好き。」

`______ is funny.`  
`I like ______ .`

### 7. 声だけ4連発 — 書かない
状況を少し変えながら、リズムで言う。

- `What is this?`
- `Is it a guitar?`
- `Who is he?`
- `I like him.`

### 8. SOLO
**状況:** 手元の物1つ、または好きなキャラ1人を使う。

どちらか1つだけ全文を書く。

`What is this? - It's ______________________________ .`

または

`Who is he / she? - He / She is ______________________________ .`

## B — QUESTION CONTROL PANEL

### MODULE 1 — 3つの疑問スイッチ
意味から先頭を決める。

- 「〜ですか？」状態・正体 → `Are / Is ...?`
- 「〜しますか？」行動 → `Do ...?`
- 「〜できますか？」能力 → `Can ...?`

### MODULE 2 — WHセンサー
- 何 → `what`
- 誰 → `who`
- どこ → `where`
- いつ → `when`
- いくつ → `how many`

### 1. 新プレイヤーの正体
**状況:** VCに中学生らしい新プレイヤーが来た。「学生なの？」

`______ you a student?`

### 2. 毎日やってる？
**状況:** その人、いつログインしてもいる。「このゲームやってる？」

`______ you play this game?`

### 3. 川を渡れる？
**状況:** マップの先に川。泳げないと詰む。「泳げる？」

`______ you swim?`

### 4. WHセンサー4連射
**状況A:** 知らない人物 → 「誰？」 → `______ is he?`  
**状況B:** 仲間が消えた → 「どこ？」 → `______ is Ken?`  
**状況C:** 集合時刻が不明 → 「いつ？」 → `______ is the game?`  
**状況D:** 敵が大量にいる → 「何人/何体？」 → `______ ______ enemies?`

### 5. 危ない、一言だけ
**状況:** 仲間が崖の端でふざけている。長文はいらない。「気をつけろ！」

`______ careful!`

### 6. それはやるな
**状況:** 味方が危険な場所で遊ぼうとしている。「ここで遊ぶな。」

`______ play here.`

### 7. 声だけ CONTROL PANEL — 書かない
父が日本語だけ言う。本人は英語の先頭だけ即答する。

- 「学生なの？」 → Are
- 「ゲームする？」 → Do
- 「泳げる？」 → Can
- 「誰？」 → Who
- 「どこ？」 → Where
- 「何個？」 → How many

### 8. SOLO
**状況:** 海外VCの相手へ、今までの英語で質問を1つだけする。

`________________________________________________ ?`

## 運用
- DAY5と同じく、自力着手を理解判定に混ぜない。
- 状況文は本人に読ませる。父は回答後のコメントと、必要なら周辺文法を薄く触る。
- 父が毎回ゼロから笑わせるコストを減らすため、プリント側に変な/切迫した状況を置く。
- 脱線で脳が起きたら、その話題のまま同じ型を2〜4回口頭で使わせる。
- 確実な即時想起はまだ要求しない。DAY6の主目的はE11〜E13へ意味付きで初接触すること。
- A/B各1枚程度。20分対話形式でもよい。
