# 英語 DAY19 — FINAL GRAMMAR MIX / 最終2日・文法全範囲

実施予定: 2026-09-08  
位置づけ: DAY18ブラインド再生後の最終総合練習。1枚目最優先。  
INDEX: E01-E03 / E06-E17 / E19 を横断。E04/E18は学習法項目のため直接出題しない。  
重点: **`a/an`、`Do you + V + O?` と `Can you + V + O?` の区別**。  
形式: 日本語→英語の全文出力。綴りの完全性より文法構造を優先する。

## 覚えておくこと - ここだけ見てよい
- 「～しますか？」 → `Do you + V + O ...?`
- 「～できますか？」 → `Can you + V + O ...?`
- 1個の数えられる名詞 → `a/an + 単数名詞`
  - `a singer / a dictionary / a gift`
  - `an apple`
- be動詞の疑問 → `Is she ...? / Is this ...?`。`do` は入れない。
- `Does he/she ...?` は今回の教科書INDEXに明示された必須範囲ではないため、本番直前の新規導入はしない。
