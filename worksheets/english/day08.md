## A — ROUTE COMMANDS: 相手を動かす英語

### MODULE
道案内は「相手に今してほしい動作」なので、主語を言わず動詞から始める。

| やってほしいこと | 英語 |
|---|---|
| まっすぐ行け | `Go straight.` |
| 左に曲がれ | `Turn left.` |
| 右に曲がれ | `Turn right.` |
| 気をつけろ | `Be careful.` |

道を聞く:
- `How can I get to the station?`
- `Where is the station?`

### 1. THE ISLE: 仲間が迷子
**状況:** 仲間が分岐で止まった。目的地はまっすぐ先。

`________ straight.`

### 2. 左の道だけ安全
**状況:** 右は崖。左へ曲がってほしい。

`________ left.`

### 3. 崖の手前
**状況:** 仲間が崖際を走っている。DAY6で出た「気をつけろ」を今度は正式に言う。

`________ careful.`

### 4. 道を聞く
**状況:** 旅行先でstationへ行きたい。相手に「駅へはどう行けばいい？」

`How can I get to the __________________ ?`

### 5. ROUTE VOICE 4連発 — 書かない
父が日本語だけ言う。本人は英語で即答。
- まっすぐ → `Go straight.`
- 左 → `Turn left.`
- 右 → `Turn right.`
- 気をつけろ → `Be careful.`

順番を変えてもう1周。

### 6. 2 STEP ROUTE
**状況:** STARTから店へ行く。まずまっすぐ、そのあと右。

1) `Go __________________.`  
2) `Turn __________________.`

### 7. SOLO
**状況:** 相手を好きな場所へ案内する。命令文を1つだけ書く。

`______________________________________________.`

## B — WANT TO: 「したい」を後ろにつなぐ

### MODULE
`I want to + 動詞` = 「私は〜したい」

| したいこと | 英語 |
|---|---|
| 行きたい | `I want to go ...` |
| 食べたい | `I want to eat ...` |
| 見たい | `I want to see ...` |

質問:
- `Where do you want to go?`

### 1. 夏休み、海へ
**状況:** 夏休みの希望。「海へ行きたい。」

`I want to ______ to the beach.`

### 2. 現地で食べたい
**状況:** 旅行先でラーメンを食べたい。

`I want to ______ ramen.`

### 3. 見たいもの
**状況:** 大きな花火を見たい。

`I want to ______ fireworks.`

### 4. 相手にも聞く
**状況:** 海外プレイヤーに「どこへ行きたい？」と聞く。

`Where do you want to ______ ?`

### 5. NOW / PAST / WANT マトリクス — 声だけ
同じ動詞を3方向に言う。

- go → went → want to go
- see → saw → want to see
- eat → ate → want to eat

父が順番をランダムに言い、本人は英語で返す。

### 6. ALSO
**状況:** 「海へ行きたい。あと、寿司も食べたい。」

`I want to go to the beach.`  
`I ______ want to eat sushi.`

### 7. SOLO
**状況:** 本当にやりたいことを1つだけ。

`I want to ______________________________________________.`
