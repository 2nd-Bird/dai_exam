# 英語 DAY5 — WHO MODULE + THIS / THAT

実施予定: 2026-08-25  
INDEX: E06 + E08 + E10  
設計: 状況 → まず口で言う → 1語/短い穴埋め → 最後だけ1文

## A — WHO MODULE: 名前を he / she / it に圧縮する

### MODULE
- Li Ming → `he`
- Aimyon → `she`
- robot / item / animal → `it`
- 1個の数えられる名詞 → `a` / 母音の音で始まるとき `an`
- 2個以上 → 名詞を複数形へ（基本は -s）

### 1. 大会実況
**状況:** 女性プレイヤーMikaがものすごい速度で走って逃げ切った。実況で名前を毎回言うのは遅い。

`Mika can run fast.`  
→ `______ can run fast.`

### 2. 消防士の写真
**状況:** 海外の友達にLi Mingの写真を見せる。「この人、消防士。走るのも速い。」

`______ is a firefighter.`  
`______ can run fast.`

### 3. 謎ロボット
**状況:** 初めて見るロボット。人間ではない。しかも泳げるらしい。

`______ is a robot.`  
`______ can swim.`

### 4. LOOT: 1個だけ
**状況:** 宝箱に sword が1本、appleが1個。

- ______ sword
- ______ apple

### 5. LOOT: 増えた
**状況:** 次の宝箱にはappleが3個。

`three apple______`

### 6. 声だけ3連発
書かない。リズムをつけて3本言う。

- He is a firefighter. He can run fast.
- She is a singer. She can play the guitar.
- It is a robot. It can swim.

### 7. SOLO
実在人物でもゲームキャラでもよい。

`My hero is __________________.`  
`He / She / It can ______________________________.`

## B — THIS / THAT: 距離でスイッチする

### MODULE
- 手元・近い → `this`
- 離れている → `that`
- `This is ... / That is ...`
- 違うと言う → `This is not ... / That is not ...`

### 1. 手に持っている鍵
**状況:** 相手が「それ何？」と聞いた。鍵は自分の手の中。

`______ is a key.`

### 2. 部屋の向こうのバッグ
**状況:** 自分のバッグは部屋の反対側。

`______ is my bag.`

### 3. 誤認
**状況:** 手元の物を相手が「剣？」と言った。でもこれはペン。

`______ is not a sword. It is a pen.`

### 4. 遠くのりんご
**状況:** 机の向こう端にappleが1個。

`______ is ______ apple.`

### 5. POINT & SAY
実物を使う。書かない。
- 手元の物を1つ指して `This is ...`
- 離れた物を1つ指して `That is ...`
- もう1セット。

### 6. SOLO
近くと遠くを1文ずつ。

`This is ______________________________.`  
`That is ______________________________.`

## 運用
- Aが最重要。Bまで行かなくても古い紙の未実施として残さない。
- 3-5秒止まったら父が状況を一度声にする。
- 構造へ食いついたら短いモジュール説明は可。
- 脱線で脳が起きたら、その勢いで同じ型を「声だけ3連発」に変換する。
