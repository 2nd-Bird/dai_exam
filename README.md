# dai_exam

中学の定期考査対策を、教材INDEX・実行計画・日々のプリント・進捗ログ・学習条件の観察を一体で管理するリポジトリ。

## ディレクトリ

- `curriculum/` — 9/10定期考査までの実行計画
- `index/` — 教科書範囲を技能単位に分解したSource of Truth
- `worksheets/` — 日々の問題プリントのMarkdown正本
- `progress/` — 実施結果・理解状況・未実施を日付順に記録
- `learner/` — 学習が起動する条件／起動しない条件と、教材設計への反映

## 運用原則

- PDF・スキャン・画像はGitに置かない。
- 問題PDFを作る場合も、内容のMarkdown版を `worksheets/` に残す。
- 「やったページ数」ではなくINDEX上の技能の使用状況で進捗を管理する。
- `1周` = 短い誘導つきで意味と形から使えた。
- `2周` = 別文脈・別形式の初見問題で再使用できた。
- 未実施ページを「借金」として同じ形でやり直させず、必要な技能を後続DAYの新しい文脈へ埋め込む。
