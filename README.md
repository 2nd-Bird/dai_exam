# dai_exam

中学の定期考査対策を、教材INDEX・実行計画・日々のプリント・進捗ログ・学習条件の観察を一体で管理するリポジトリ。

## ディレクトリ

- `curriculum/` — 9/10定期考査までの実行計画
- `index/` — 教科書範囲を技能単位に分解したSource of Truth
- `worksheets/` — 日々の問題プリントのMarkdown正本
- `progress/` — 実施結果・理解状況・未実施を日付順に記録
- `learner/` — 学習が起動する条件／起動しない条件と、教材設計への反映

## 問題作成時の必須読込順

英語・数学のDAY問題を作るときは、**毎回最初にGitHubの最新状態を次の順で読む。**

1. `README.md`
2. 対象科目の `curriculum/`
   - 基本計画を読む。
   - `実績反映プラン` など、より新しい補正計画があればそちらも読む。
3. 対象科目の `index/`
4. 対象科目の `progress/`
5. `learner/learning_conditions.md`
6. 対象科目の直近 `worksheets/` を必要数だけ読む

### 英語
- `curriculum/english/英語_定期考査_2周実行計画_2026-09-10.md`
- `curriculum/english/` 内の最新の実績反映プラン
- `index/english/英語テキスト_INDEX_p24-63.md`
- `index/english/英語語彙_INDEX_p24-63.md` **（必須。実際の教科書語彙・表現の正本）**
- `progress/english.md`
- `learner/learning_conditions.md`
- `worksheets/english/` の直近DAY

### 数学
- `curriculum/math/数学_定期考査_2周実行計画_2026-09-10.md`
- `index/math/数学テキスト_INDEX_p10-99.md`
- `progress/math.md`
- `learner/learning_conditions.md`
- `worksheets/math/` の直近DAY

## 前日FBを受けたときの判断順

問題を作る前に、次の順で現在地を評価する。

1. **前日の実績** — 何を実施し、どこまで理解・利用できたか
2. **INDEX上の理解状況** — `未 / 触 / 要確認 / 1周 / 2周` 等の状態
3. **カリキュラム上の現在地** — 今日扱うべき技能と、未回収技能
4. **残日数** — 9/3の2周完了、9/10本番から逆算

カリキュラムは予定表であり絶対ではない。未定着部分は別問題・別文脈へ再利用するが、未実施プリントをそのまま「借金」として積まない。

## 教科書スキャンの参照ルール

### 正本はまずMarkdown

問題作成時の第一参照先は、**GitHub上の `index/`、`curriculum/`、`progress/`、`worksheets/`** とする。

`index/` は全文転記ではなく、教科書をページ・概念・問題型・技能単位に構造化した教材生成用MDである。現時点で、教科書全ページの逐語的全文MarkdownはGitHubには置いていない。

**英語は例外的に語彙の取りこぼしが重大なので、文法INDEXだけで問題を作ってはいけない。** `index/english/英語語彙_INDEX_p24-63.md` を必ず併読し、その日の対象ページの語彙を問題文・選択肢・日本語→英語に実際に使う。語彙INDEXが未整備／抽象カテゴリしかない場合は、該当ページの元スキャンを確認してから出題する。

### スキャンPDFは必要なページだけ

INDEXだけでは不足する場合に限り、INDEXに記載されたページ番号から**該当ページだけ**元スキャンを参照する。

参照が必要な例:
- 教科書本文の正確な表現・会話文を確認したい
- ページ固有の語彙・図・表・地図・問題形式を使いたい
- INDEXの記述だけでは出題意図が曖昧

原則として、**問題作成のたびにPDF全体を再レンダリング・全ページ画像化・全OCRしない。**

元スキャン:
- 英語: `スキャン英語テキスト.pdf`（対象 p24-63）
- 数学: `スキャン数学テキスト1.pdf` / `スキャン数学テキスト2.pdf`（対象 p10-99）

PDF・スキャン・画像そのものはGitに置かない。

## 出力・更新ルール

- 問題PDFを作る場合も、内容のMarkdown正本を `worksheets/{subject}/` に保存する。
- **ユーザーへ制作出力するプリントは、英語・数学とも本人用A4 2枚セットのみ。** A/Bの個別PDF、保護者用解答・見取りPDFなどは、明示依頼がない限り制作・提示しない。
- FBを受けたら `progress/{subject}.md` を更新する。
- 理解状態が変わったら対象科目のINDEXも更新する。
- 日程を変える必要があるときだけ `curriculum/` を更新する。
- 通常の科目チャットでは自科目だけを更新する。英語チャットで数学、数学チャットで英語のファイルを変更しない。
- `learner/learning_conditions.md` は原則参照のみ。科目横断で持続する新しい学習条件が判明した場合だけ更新する。

## 進捗の定義

- 「やったページ数」ではなくINDEX上の技能の使用状況で進捗を管理する。
- `1周` = 短い誘導つきで意味と形から使えた。
- `2周` = 別文脈・別形式の初見問題で再使用できた。
- 理解、状況利用、即時想起、答案化、自力着手を必要に応じて分離して評価する。
