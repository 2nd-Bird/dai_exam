# 回収方針 2026-08-29以降

## 現状
文法は1周目を概ね進めたが、語彙は**1周目未完**。特に以下が薄い。
- p24 Starter 53語・句
- p34 数字体系
- p42 月・日付
- p54 地図語彙
- p62-63 食材・注文語彙
- 各PartのNew Wordsのうち、プリントで使っていない語

## 深さを分ける
1. VA: 9/3までに最低2回再遭遇。うち主要語は1回以上日本語→英語。
2. VB: 9/3までに最低1回意味確認＋可能な範囲で2回目を混合問題へ。
3. VC: 読解・地図・メニュー文脈で意味を拾う。全語の綴り暗記は要求しない。

## 2周目への割当
- DAY10: p24-31 語彙 + E01-E03
- DAY11: p32-41 語彙 + E05-E08
- DAY12: p42-49 語彙 + E09-E13
- DAY13: p50-55 + p62-63 語彙 + 実用英語
- DAY14: p56-61 語彙 + E16-E17
- DAY15: 全範囲語彙の初見混合診断。VAの弱点を優先。

## プリント設計
- 文法だけを同じ少数語（game/music/soccer等）で回さない。
- **文法問題の名詞・動詞・場所・食べ物を、その日の対象ページの教科書語彙へ置き換える。**
- 前半: 認識・短い出力を多めに。
- 後半: 日本語→英語を全文で書く。語彙も答案化する。
- 紙上問題数を増やす場合も、説明ブロックは増やさない。
