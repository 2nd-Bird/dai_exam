## 方針変更
9/6予定のミニ模試②は延期する。模試で未定着を確認し続けるより、まず基本構文を覚えるためのドリルへ切り替える。

### ドリル形式
- プリント上部に基準文と変形ルールを常時表示。
- `S / V / O / C / Aux / Neg / Q` を語の下に表示する。
- 日本語側にも「だれが / なにを / どうする」に対応する意味役割を付け、日本語SOVと英語SVOを対比する。
- 同じ素材を固定して、肯定 → 否定 → Do...? → can → cannot → Can...? → What/Where/How many へ反復変形する。
- 1問ごとに **口で1回 → 全文を書く1回**。
- これは診断ではなく、記憶を作るための出力練習。
